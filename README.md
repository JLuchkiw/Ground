Ground is an interactive grounding and mindfulness app that helps users refocus using the 5-4-3-2-1 grounding technique.  
This project is designed as a learning journey in full-stack and mobile development, starting with a Python-based console MVP. The web version is a continuation of the original Python MVP and now uses a modern JavaScript-based stack for accessibility and scalability.

## Project Stages
1. MVP (Python Console App) - Command-line interaction guiding users through grounding steps.
2. Web App Version - Rebuilt using JavaScript with React for the frontend (original prototype built with FastAPI + Python).
3. Mobile App Version - Built with React Native or Flutter for iOS & Android.

## Tech Stack (Web App)
- JavaScript ES6+ - Core application logic
- React (via Vite) - UI rendering and component state management
- JSX - JavaScript syntax extension for building UI declaratively
- Tailwind CSS - For rapid styling
- PostCSS + Autoprefixer - Style processing and browser compatability
- Vite - Fast development server and build tool

## Tech Stack (Legacy MVP)
- Python 3.11+
- No dependencies initially (standard library only)

## Getting Started
```bash
git clone https://github.com/JLuchkiw/Ground.git
cd Ground/mvp_console
python grounding_companion.py
```
